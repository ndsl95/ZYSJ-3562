# 5.5" 屏背光驱动选型与 BOM（线性恒流方案）

> 适用对象：ZYSJ-2362B（RK3562）主板 + F55H40-152（5.5" 480×960 MIPI 2-lane）转接板
> 日期：2026-09-28
> 结论：**不需要升压 / 升降压。一颗线性恒流驱动器即可，首选 惠海 H7304C（SOT23-6）**
> ⚠️ 2026-09-27 版结论（"必须升降压，首选 TI TPS923653"）已作废 —— 前提被实测推翻，见 §1。
> 文件名里的"升降压"是历史遗留，保留以维持链接不变。

---

## 1. 结论为什么改了

09-27 版依据屏规格书的 `Vf = 11.2 ~ 13.2V @ 80mA`，认为 12V 输入"正好卡在输出窗口中间"，所以选了升降压。

**实测把这个前提推翻了：**

| 测量项 | 值 | 条件 |
|---|---|---|
| T113 板上背光输出滤波电容对 GND 电压 | **11.0V** | 亮度拉满（占空比 100%），排除了万用表在 PWM 下读到平均值的误差 |
| 折算灯串真实 Vf | **≈ 10.8V** | 再减去采样电阻 R7 压降（2.7Ω × ~74mA ≈ 0.2V） |

10.8V ÷ 4 串 ≈ 2.7V/颗，与白光 LED @20mA 的典型 Vf 一致，也和屏"4 串 4 并 / 80mA"的结构自洽 —— 这个数可信，而且**比规格书下限还低**。

于是拓扑的选择变成：

| 拓扑 | 判定 |
|---|---|
| 升压（MP3302 / AP3031 / SY7201 等） | ❌ 升压不能降压，这里压根不需要升 |
| 升降压（TPS923653） | ❌ 能覆盖，但为 1.2V 的压差上电感 + 肖特基 + OVP 分压 + 补偿网络，属过度设计 |
| **线性恒流（low-side sink，共阳）** | ✅ 直接把多出来的 1.2V "吃掉"，无电感、无开关噪声、无 EMI |

> 另：T113 板上那颗 **MP3302 是 2.5~6V 输入的升压**，靠 T113 的 5V 供电才能工作，在 RK3562 的 12V 上**不能照搬**。

## 2. 余量核算（选型的硬约束）

| 工况 | 灯串 Vf | 相对 12V 的余量 |
|---|---|---|
| 常温 80mA（实测折算） | ≈ 10.8V | ≈ **1.2V** |
| 冷机 -10°C（Vf 温度系数按 +0.4V 估） | ≈ 11.2V | ≈ **0.8V** |

**驱动 IC 的最低压差（dropout）必须 ≤ 0.5V @ 80mA。**

- 0.8V（冷机最差余量）− 0.5V（dropout）= 还有 0.3V 留给 12V 轨跌落和采样误差
- 一旦选到 dropout 大于 0.5V 的型号，冷机时会掉出恒流区，表现为**背光偏暗**（不是完全不亮，容易误判成"驱动没工作"）

---

## 3. 首选：惠海 H7304C（SOT23-6）

| 需求 | H7304C | 判定 |
|---|---|---|
| 拓扑 | 线性降压恒流（low-side sink，共阳） | ✅ |
| 输入电压 | 2.5 ~ 40V | ✅ 覆盖 12V |
| 输出电流 | 10 ~ 200mA，外置一颗电阻设定 | ✅ 覆盖 80mA |
| 功率管 | 内置 60V 耐压 MOS，无需外置 | ✅ |
| 调光 | DIM 脚 PWM 调光（**最高 25kHz**） | ⚠️ 见 §4 |
| 封装 | **SOT23-6**，无散热焊盘 | ✅ 手焊友好 |
| **最低压差** | **公开资料未给出数值** | ⚠️ **上板前必须查数据手册确认 ≤ 0.5V** |
| 保护 | 过温保护（触发后自动降电流） | ✅ |
| 静态电流 | 典型 100µA | ✅ |

### 备选：惠海 H7310（ESOP-8）—— 唯一有公开压差指标的

| 项目 | H7310 |
|---|---|
| 输入 / 电流 | 2.5 ~ 85V / 16 ~ 1500mA，外置 R_CS 设定 |
| 内置 MOS | 100V |
| **最低压差** | 官方明确："电流 1000mA 时，转折电压 **< 0.5V**" → 80mA 下远小于此，余量充裕 |
| 封装 | ESOP-8，底部散热焊盘与 LED 脚相连 → **需要热风枪，或从侧面补焊** |
| 调光 | DIM PWM，≤ 25kHz |

### 已排除：惠海 H7302（SOT23-6）

封装和电流范围本来都合适，但数据手册明确标注 **"最低压差要求 3V"**，远大于 0.8V 余量，冷机必然掉出恒流区。❌

## 4. 调光怎么接（40kHz 的坑）

主板 `pwm-backlight` 是 **40kHz**；上面这些线性恒流 IC 的 DIM 都标注 **调光频率 ≤ 25kHz**。两条路：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A. 改设备树降频** | 把背光 PWM 周期从 `25000ns` 改成 `50000ns`（20kHz），再让 `LCD-ADJ` 进 DIM | ✅ 保留可调光，改动只有一行 DTS |
| **B. 不调光** | `JP1` 短接 → DIM 拉高到 3.3V → 恒流满亮 | ✅ 最简，先点亮再谈调光 |

DIM 是 **PWM 型**输入（不是模拟型），所以：

- 传 PWM 时：R6（1k）串阻保留，**C4（100nF）不贴** —— RC 只会把方波滤成直流电平，PWM 型 DIM 会把直流电平当成常亮/常灭
- 若想用模拟调光，得换支持 ADIM 的型号

## 5. 背光 BOM

| 位号 | 型号 / 值 | 封装 | 作用 | 与 09-27 版相比 |
|---|---|---|---|---|
| **U1** | 惠海 **H7304C**（备选 H7310） | SOT23-6 | 线性恒流驱动，80mA | **替换**原 `BUCK-BOOST-CC-LED-80mA` 占位块 |
| **R1** | 见 §5.1 | 0805 | 恒流采样，设定 80mA | **新增** |
| C1 | 10µF / 25V | 0805 | 12V 输入储能 | 沿用 |
| R6 | 1k | 0402/0603 | DIM 串阻 | 沿用 |
| C4 | 100nF | 0402/0603 | DIM 滤波 | 沿用位号，**PWM 调光时不贴** |
| JP1 | 2pin 跳线 | — | 常亮档（DIM 拉 3V3） | 沿用 |
| P2 | 2pin 焊盘 | — | 外部 PWM 输入 | 沿用 |

**已删除、不用再画**：功率电感 L1、肖特基 D1、OVP 分压 R_OVP1 / R_OVP2、R_FSET、C_COMP、C_SENSE、C_VCC —— 全部是升降压方案的外围，线性方案一个都不需要。

### 5.1 R1（恒流采样电阻）

```
I_LED = V_CS / R1      →      R1 = V_CS / 0.08A
```

- `V_CS` 是所选 IC 的采样基准（**公开资料未给出，必须从数据手册取**）
- 常见取值下的阻值：

| V_CS | R1 | 功耗 I²R |
|---|---|---|
| 100mV | **1.25Ω**（取 1.2Ω 或 1.3Ω，1% 精度） | ≈ 8mW（0805 足够） |
| 200mV | 2.5Ω | ≈ 16mW |

- 采样电阻串在恒流回路里（屏 LEDK → U1 → R1 → GND），**必须用 1% 精度**，输出电流精度直接跟它走

## 6. 怎么连（拓扑 + 逐点）

**拓扑：共阳（common anode）线性恒流 —— 屏的 LEDA 直接借 12V，驱动器把 LEDK 拉低并稳流。**

```
                        ┌───────────── 转接板 ─────────────┐
主板 J1.1/2/3 (LED+ 12V) ─┤ BL_12V ─┬─ J2.35/36 ─► 屏 LEDA
                          │         ├─ U1.VIN
                          │         └─ C1 ── GND
主板 J1.4..8  (LED-)     ─┤  不使用（NC）
                          │
                          │ U1.LED ◄── J2.28/29 ── 屏 LEDK
                          │ U1.CS  ──[R1]── GND
                          │ U1.GND ── GND
                          │
主板 LCD-ADJ (40kHz PWM) ─┤ BL_DIM ◄─ JP1(3V3 常亮) 或 R6 ── P2(外部 PWM)
                        └───────────────────────────────────┘
```

逐点对照：

| 网络 | 连到哪 | 说明 |
|---|---|---|
| `BL_12V` | 主板 J1.1/2/3（LED+ 12V）→ U1.VIN、C1+、**J2.35/36（屏 LEDA）** | LEDA 从"驱动 IC 的输出"改成**直接挂 12V**（共阳接法） |
| `LED_K` | 屏 J2.28/29（LEDK）→ **U1.LED**（内部 MOS 漏极 / 恒流端） | 驱动器在这条路上沉电流 |
| `LED_CS`（新增） | U1.CS → **R1** → GND | 采样回路，设定 80mA |
| `BL_DIM` | U1.DIM ← JP1（常亮，接 3V3）或 R6 ← P2（外部 PWM） | 见 §4 |
| `GND` | U1.GND、C1−、R1、J1/J2 各地 | 必须共地 |
| `NC` | 主板 J1.4~8（LED−） | 本设计不使用 |

⚠️ **引脚号以数据手册为准。** 上表 `U1` 只标了功能（VIN / GND / DIM / LED / CS），SOT23-6 的具体脚位必须按实际型号的数据手册核对后再画封装 —— 别照抄二手资料。

## 7. 上板前必须确认的 4 件事

- [ ] **12V 轨实测**：RK3562 的 BL JACK 12V 脚，空载 / 带载各多少 V（决定 §2 的余量是否成立）
- [ ] **驱动 IC 最低压差**：≤ 0.5V @ 80mA 才能用；H7304C 需查手册，H7310 已有公开指标
- [ ] **R1 阻值**：按数据手册的 `V_CS` 算
- [ ] **调光信号**：亮度拉 100% 时 LED+ 是不是干净 12V？`LCD-ADJ` 是不是独立的 40kHz 逻辑 PWM、电平 3.3V 还是 1.8V？
