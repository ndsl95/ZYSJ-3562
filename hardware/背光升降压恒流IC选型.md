# 5.5" 屏背光驱动选型与 BOM（线性恒流方案）

> 适用对象：ZYSJ-2362B（RK3562）主板 + F55H40-152（5.5" 480×960 MIPI 2-lane）转接板
> 日期：2026-09-28
> 结论：**不需要升压 / 升降压。一颗线性恒流驱动器即可，选定 数明半导体 SLM421A（SOP8-EP）**
> ⚠️ 2026-09-27 版结论（"必须升降压，首选 TI TPS923653"）已作废 —— 前提被实测推翻，见 §1。
> ⚠️ 2026-09-28 上午版的 "首选 惠海 H7304C" 已降级为候选 —— 其 dropout 无公开数据，无法验证方案是否成立；改用 SLM421A，参数可查。
> 文件名里的"升降压"是历史遗留，保留以维持链接不变。

---

## 1. 结论为什么改了

09-27 版依据屏规格书的 `Vf = 11.2 ~ 13.2V @ 80mA`，认为 12V 输入"正好卡在输出窗口中间"，所以选了升降压。

**实测把这个前提推翻了：**

| 测量项 | 值 | 条件 |
|---|---|---|
| T113 板上背光输出滤波电容对 GND 电压 | **11.0V** | 亮度拉满（占空比 100%），排除了万用表在 PWM 下读到平均值的误差 |
| 折算灯串真实 Vf | **≈ 10.8V** | 再减去采样电阻 R7 压降（2.7Ω × ~74mA ≈ 0.2V） |

10.8V ÷ 4 串 ≈ 2.7V/颗，与白光 LED @20mA 的典型 Vf 一致，也和屏"4 串 4 并 / 80mA"的结构自洽 —— 这个数可信，而且**比规格书下限还低**。

于是拓扑的选择变成：

| 拓扑 | 判定 |
|---|---|
| 升压（MP3302 / AP3031 / SY7201 等） | ❌ 升压不能降压，这里压根不需要升 |
| 升降压（TPS923653） | ❌ 能覆盖，但为 1.2V 的压差上电感 + 肖特基 + OVP 分压 + 补偿网络，属过度设计 |
| **线性恒流（low-side sink，共阳）** | ✅ 直接把多出来的 1.2V "吃掉"，无电感、无开关噪声、无 EMI |

> 另：T113 板上那颗 **MP3302 是 2.5~6V 输入的升压**，靠 T113 的 5V 供电才能工作，在 RK3562 的 12V 上**不能照搬**。

## 2. 余量核算（选型的硬约束）

| 工况 | 灯串 Vf | 相对 12V 的余量 | 扣掉 IC dropout 后剩余 |
|---|---|---|---|
| 常温 80mA（实测折算） | ≈ 10.8V | ≈ **1.2V** | 1.2 − 0.43 = **0.77V** |
| 冷机 -10°C（Vf 温度系数按 +0.4V 估） | ≈ 11.2V | ≈ **0.8V** | 0.8 − 0.43 = **0.37V** |

SLM421A 在 80mA 下的 dropout 取数据手册 60mA→0.35V 与 100mA→0.5V 之间插值：**≈ 0.43V**。

**驱动 IC 的最低压差（dropout）要求：≤ 0.5V @ 80mA。**

- 冷机最差余量 0.8V − 0.43V = **0.37V** 留给 12V 轨跌落与器件误差
- 一旦选到 dropout 大于 0.5V 的型号，冷机时会掉出恒流区，表现为**背光偏暗**（不是完全不亮，容易误判成"驱动没工作"）

> 📌 **本版修正**：09-28 上午版用"CS 脚在 LED 电流回路里"的拓扑，余量算成 `0.8 − 0.5 = 0.3V`（且漏扣采样电阻压降）。
> 改用 SLM421A 后 **SET 是编程脚，不在 LED 电流回路里**，回路中不存在采样电阻压降，该问题自动消除，余量反而比原来更宽。

## 3. 首选：数明半导体 SLM421A（SOP8-EP）

| 需求 | SLM421A | 判定 |
|---|---|---|
| 拓扑 | 双通道线性恒流（low-side sink） | ✅ |
| 输入电压 | 4.5 ~ 42V | ✅ 覆盖 12V |
| 输出电流 | 每通道 15 ~ 200mA，SET 脚外接电阻设定 | ✅ 覆盖 80mA |
| 功率管 | 内置，无需外置 | ✅ |
| **最低压差 dropout** | **20mA→0.30V / 60mA→0.35V / 100mA→0.5V / 200mA→0.8V**（公开数据）<br>→ **80mA 约 0.43V ✅ ≤0.5V 达标** | ✅ **可验证** |
| **调光输入门槛** | **VIH ≥ 1.4V / VIL ≤ 0.4V** | ✅ **1.8V 与 3.3V 电平都能驱动** |
| 调光 | PWM1 脚，100Hz ~ 20kHz | ⚠️ 40kHz 超限，见 §4 |
| 恒流精度 | 每通道 ±5% | ✅ |
| 压降/负载调整率 | 0.1 %/V | ✅ |
| 保护 | 过温线性降电流（135°C 起降 / 160°C 归零） | ✅ |
| 封装 | **SOP8-EP**（带底部散热焊盘，同时也是芯片地） | ⚠️ 手焊需热风枪或侧面补焊 |
| 静态电流 | 典型 400µA | ✅ |

> 双通道只用一个通道。通道 2 的处理见 §6。

### 3.1 为什么不用惠海 H7304C（原首选，现降级为候选）

封装（SOT23-6）和电流范围都合适，且比 SOP8-EP 好手焊。**但它的最低压差没有公开数据**，
而 dropout ≤ 0.5V 是本方案成立的硬条件 —— 参数查不到就无法验证，不能作为首选。

### 3.2 其它候选与排除记录

| 型号 | 厂商 | 判定 |
|---|---|---|
| **H7310** | 惠海 | ⚠️ 候选。官方有公开指标（1000mA 时转折电压 <0.5V，80mA 下远小于此），但 **ESOP-8 带散热焊盘**，比 SLM421A 更难焊 |
| H7302 | 惠海 | ❌ 数据手册明确"最低压差要求 3V"，远大于 0.8V 余量，冷机必然掉出恒流区 |
| CAT4004A / CAT4004B | onsemi | ❌ 线性度极好（dropout 仅 50~75mV）**但 VIN 上限只有 5.5V**，接 12V 直接炸。这类是单节锂电（3~4.2V）应用 |
| TPS923653 | TI | ❌ 升降压，过度设计，09-27 版已废除 |

> **选型教训**：`VIN 上限` 要第一个看 —— 手机/电池背光用的线性恒流 IC 大多只有 5.5V，能筛掉一大半。

### 3.3 选型判据（后续换型号时按此表筛）

| 指标 | 门槛 |
|---|---|
| 拓扑 | 线性恒流，低边 sink |
| VIN | ≥ 12V（建议 ≥20V 裕量） |
| 输出电流 | 可设定到 80mA |
| **dropout @ 80mA** | **≤ 0.5V**，且**必须有公开数据** |
| PWM 输入门槛 | 越低越好（≤1.4V 最佳） |
| 封装 | 优先不带底部散热焊盘 |

## 4. 调光怎么接（40kHz 的坑）

主板 `pwm-backlight` 是 **40kHz**；SLM421A 的 PWM1 标注 **0.1 ~ 20kHz**。两条路：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A. 改设备树降频** | 把背光 PWM 周期从 `25000ns` 改成 `50000ns`（20kHz），再让 `LCD-ADJ` 进 PWM1 | ✅ 保留可调光，改动只有一行 DTS |
| **B. 不调光** | `JP1` 短接 → PWM1 拉高到 3.3V → 恒流满亮 | ✅ 最简，先点亮再谈调光 |

PWM1 是 **PWM 型**输入（不是模拟型），所以：

- 传 PWM 时：R6（1k）串阻保留，**C4（100nF）不贴** —— RC 只会把方波滤成直流电平，PWM 型输入会把直流电平当成常亮/常灭
- 若想用模拟调光，得换支持 ADIM 的型号

> ✅ **电平问题已解除**：主板 `LCD-ADJ` 实测档案里标注"3.3V 还是 1.8V 待实测"，
> 而 SLM421A 的 VIH 门槛只有 1.4V —— **两种电平都能可靠驱动**，这条风险不再是阻塞项。
> （PWM1 脚的绝对最大额定值是 -0.3 ~ 48V，3.3V 也远未触顶。）

## 5. 背光 BOM

| 位号 | 型号 / 值 | 封装 | 作用 | 与 09-27 版相比 |
|---|---|---|---|---|
| **U1** | 数明半导体 **SLM421A** | **SOP8-EP** | 线性恒流驱动，80mA | **替换**原 `BUCK-BOOST-CC-LED-80mA` 占位块 |
| **R1** | **12.7kΩ 1%**（见 §5.1） | **0805** | 电流设定（SET） | **新增** |
| C1 | 10µF / 25V | **0603** | 12V 输入储能 + 芯片输入电容 | 沿用 |
| R6 | 1k | **0805** | PWM1 串阻 | 沿用 |
| C4 | 100nF | **0603** | 调光滤波 | 沿用位号，**PWM 调光时不贴** |

| JP1 | 2pin 跳线 | — | 常亮档（PWM1 拉 3V3） | 沿用 |
| P2 | 2pin 焊盘 | — | 外部 PWM 输入 | 沿用 |

> 📦 **封装约定（2026-09-28 定）**：**电容一律 0603，电阻一律 0805** —— 按手上现有库存，不新增采购。
> 注意 0603 的 10µF/25V 是 X5R/X7R，在 12V 直流偏压下实际容量会掉到标称的一半左右；
> 但 C1 在这里只作输入旁路（手册要求 0.1~10µF），掉到 3~5µF 完全够用，不必为此换 0805。

**已删除、不用再画**：功率电感 L1、肖特基 D1、OVP 分压 R_OVP1 / R_OVP2、R_FSET、C_COMP、C_SENSE、C_VCC —— 全部是升降压方案的外围，线性方案一个都不需要。

### 5.1 R1（电流设定电阻 R_SET）

数据手册给的公式（注意单位是 kΩ / mA）：

```
I_LED(mA) = 1000 / R_SET(kΩ)          →          R_SET(kΩ) = 1000 / I_LED(mA)
```

手册例：外接 **5kΩ → 输出 200mA**（已核对，公式自洽）。

| 目标电流 | R_SET | E96 标准值（1%） | 实际电流 |
|---|---|---|---|
| 80mA（规格书额定） | 12.5kΩ | **12.7kΩ** ← 选用 | 78.7mA |
| | | 12.4kΩ | 80.6mA |
| ≈74mA（与 T113 板已跑通工况一致） | 13.5kΩ | 13.3kΩ | 75.2mA |

- 选用 **12.7kΩ**：最接近 80mA 额定而不超规格
- 精度 **1% 足够**（IC 本身恒流精度就是 ±5%）
- **功耗可忽略** —— SET 是编程脚，电流在 µA 级，0603 封装绰绰有余
- ⚠️ 与 09-28 上午版的区别：R1 从"回路里的采样电阻"（1.25Ω）变成"SET 编程电阻"（12.7kΩ），**量级差一万倍，画图时不要照抄旧值**

## 6. 怎么连（拓扑 + 逐点）

**拓扑：共阳（common anode）线性恒流 —— 屏的 LEDA 直接借 12V，驱动器把 LEDK 拉低并稳流。**

```
                        ┌───────────── 转接板 ─────────────┐
主板 J1.1/2/3 (LED+ 12V) ─┤ BL_12V ─┬─ J2.35/36 ─► 屏 LEDA（阳极）
                          │         ├─ U1.VIN  (pin3)
                          │         └─ C1 ── GND
主板 J1.4..8  (LED-)     ─┤  不使用（NC）
                          │
                          │ U1.LED1 (pin2) ◄── J2.28/29 ── 屏 LEDK（阴极）
                          │       └─ 内部 MOS ── U1.GND (pin7) / EP ── GND
                          │
                          │ U1.SET1 (pin8) ──[ R1 12.7k ]── GND
                          │
主板 LCD-ADJ (40kHz PWM) ─┤ BL_DIM ◄─ JP1(3V3 常亮) 或 R6 ── P2(外部 PWM)
                        └───────────────────────────────────┘
```

### 6.1 U1 引脚对照表（SOP8-EP）

| 手册脚号 | 名称 | 接到哪个网络 | 说明 |
|---|---|---|---|
| 1 | PWM1 | `BL_DIM` | 调光输入，VIH ≥1.4V |
| 2 | LED1 | `LED_K` | 恒流输出端，接屏 LEDK（低边 sink） |
| 3 | VIN | `BL_12V` | 芯片供电 |
| 4 | SET2 | — | 通道 2 不用 |
| 5 | PWM2 | — | 通道 2 不用（见下） |
| 6 | LED2 | — | 通道 2 不用 |
| 7 | GND | `GND` | 芯片地 |
| 8 | SET1 | `LED_SET` | 接 R1 到地，设定 80mA |
| EP | 散热焊盘 | `GND` | **亦为芯片地，必须接到 GND** |

**通道 2 的处理**：数据手册未规定空闲通道如何接。建议 **PWM2 接 GND**（明确关断通道 2），
LED2 / SET2 悬空。若想省事全部悬空也可以 —— LED2 开路时该通道不会流过电流。

### 6.2 逐点对照

| 网络 | 连到哪 | 说明 |
|---|---|---|
| `BL_12V` | 主板 J1.1/2/3（LED+ 12V）→ U1.VIN、C1+、**J2.35/36（屏 LEDA）** | LEDA 直接挂 12V（共阳接法） |
| `LED_K` | 屏 J2.28/29（LEDK）→ **U1.LED1 (pin2)** | 驱动器在这条路上沉电流 |
| `LED_SET` | **U1.SET1 (pin8) → R1 → GND** | 电流设定回路（**不在 LED 电流路径上**） |
| `BL_DIM` | U1.PWM1 (pin1) ← JP1（常亮，接 3V3）或 R6 ← P2（外部 PWM） | 见 §4 |
| `GND` | U1.GND (pin7) + EP、C1−、R1、J1/J2 各地 | 必须共地 |
| `NC` | 主板 J1.4~8（LED−） | 本设计不使用 |

### 6.3 手册的其它建议

- ✅ **输入电源端对地接 0.1µF ~ 10µF 陶瓷电容** —— 已由 C1（10µF/25V）满足
- ⭕ **LED 脚对地接 100nF 陶瓷电容**（手册建议"特别是汽车电子场景"）—— 本应用可不加；
  若要加，需在 PCB 上为 U1.LED1 脚预留一个 100nF 位置

## 7. 上板前必须确认的事

- [ ] **12V 轨实测**：RK3562 的 BL JACK 12V 脚，空载 / 带载各多少 V（决定 §2 的余量是否成立）
- [x] ~~驱动 IC 最低压差~~ —— **已关闭**：SLM421A 公开数据，80mA 约 0.43V ≤ 0.5V ✅
- [x] ~~R1 阻值~~ —— **已关闭**：按手册公式定为 12.7kΩ（78.7mA）
- [x] ~~调光信号电平~~ —— **风险已解除**：SLM421A 的 VIH 门槛仅 1.4V，1.8V / 3.3V 均可驱动
- [ ] **调光频率**：40kHz 超 IC 上限，需改 DTS 降到 20kHz，或不调光走 JP1
- [ ] **通道 2 处理**：PWM2 是否接地（建议接地关断）
- [ ] **SOP8-EP 焊接**：EP 焊盘需要热风枪或从侧面补焊，确认自有焊接条件
