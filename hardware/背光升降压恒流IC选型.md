# 5.5" 屏背光升降压恒流 IC 选型

> 适用对象：ZYSJ-2362B（RK3562）主板 + F55H40-152（5.5" 480×960 MIPI 2-lane）转接板
> 日期：2026-09-27
> 结论：**首选 TI TPS923653DYYR（SOT-23-THN-14）**

---

## 1. 需求

| 项目 | 值 | 来源 |
|---|---|---|
| 输入电压 | **12V** | 主板 MIPI FPC `LED+`（pin 1/2/3） |
| 输出电流 | **80mA**（4 串 × 20mA） | 屏规格书 §6 |
| 输出电压 | **11.2 ~ 13.2V** | 屏规格书 §6（Vf，IF=80mA） |
| 灯串结构 | 4 串 4 并，公共阴极 | 屏规格书 + 外形图纸 |
| 调光 | 可选，主板有 40kHz PWM | 主板实测档案 §7 |

**关键约束：输入 12V 正好落在输出窗口 11.2~13.2V 的中间。**

## 2. 为什么必须升降压

| 拓扑 | 问题 |
|---|---|
| 纯升压（MP3302 / AP3031 / SY7201 等） | 升压不能降压。Vf 偏低的样品（11.2V < 12V）掉出调节范围，电流失控 |
| 纯降压（MT7203 / PT4115 等） | Vf 偏高的样品（13.2V > 12V）根本点不亮，达不到标称 80mA / 700 cd/m² |
| 串限流电阻 | Vf 离散跨度 2V，电阻只对"典型样品"算得准，换一颗就偏亮或偏暗 |
| **升降压恒流** ✅ | Vin 高于或低于 Vout 都能稳流，覆盖全部样品 |

> ⚠️ 顺带排除：T113 板上用的 **MP3302 是 2.5~6V 输入的升压**，在 T113 板（5V 供电）能用，但在 RK3562 板（12V 供电）**不能照搬**。

## 3. 首选：TPS923653DYYR

### 3.1 参数对照

| 需求 | TPS923653 | 判定 |
|---|---|---|
| 拓扑 | Boost / **Buck-Boost** | ✅ 覆盖 12V 两侧 |
| 输入电压 | 4.5 ~ 65V | ✅ |
| 输出电压范围 | **5.5 ~ 65V** | ✅ 低 Vf 样品（11.2V）也稳得住 |
| LED 接法 | **共阴极（common cathode）** | ✅ 屏的 LEDK 就是 4 串公共阴极，天然匹配 |
| 恒流基准 | **V_REF = 200mV** | ✅ 与 MP3302 同一套算法，参数可平移 |
| 电流能力 | 内置 150mΩ 低边 NMOS，典型限流 **3A** | ✅ 只要 80mA，裕量极宽 |
| 调光 | EN/PWM 脚（拉高=常亮 / 拉低=关断 / PWM 输入=调光）<br>ADIM/HD 脚（模拟 / 混合调光） | ✅ 支持 **150ns 最小脉宽**，40kHz PWM 可直接进，**不需要 RC 滤波** |
| 封装 | **SOT-23-THN-14，4.2 × 3.3mm**，无散热焊盘 | ✅ 比 WSON / VSON 好焊 |
| 展频 | TPS923653 支持（±7%，2kHz 调制） | ✅ 降 EMI |
| 保护 | LED 开路/短路、采样电阻开路/短路、逐周期限流、热关断、可配置热折返、FAULT 输出 | ✅ |

只有 **TPS923652 / TPS923653** 提供 SOT-23-THN 封装；654 / 655 只有 VSON(14) / WSON(12)。

### 3.2 恒流采样电阻

```
R_SENSE = V_REF / I_LED_FS      V_REF = 200mV

80mA  →  2.5Ω
74mA  →  2.7Ω   ← 与 T113 转接板新版所用 R7 完全一致
```

**建议取 2.7Ω**：与已跑通的 T113 板保持一致，同时给 LED 留约 7% 余量，不把灯顶到规格书上限。

采样电阻串在 LED 回路里，CSP / CSN 跨接在它两端（共阴极接法：LEDK → R_SENSE → GND）。

### 3.3 开关频率设定（FSET 脚对 AGND 接电阻）

| 频率 | R_FSET | 频率 | R_FSET |
|---|---|---|---|
| 100kHz | 232kΩ | 600kHz | 38kΩ |
| 200kHz | 138kΩ | 800kHz | 28kΩ |
| 300kHz | 83kΩ | 1MHz | 23kΩ |
| **400kHz** | **59kΩ** | 2.2MHz | 9kΩ |

本应用功率很小（12V × ~100mA 输入），**建议 100~400kHz**：频率越低，效率和热表现越好。

### 3.4 外围元件清单

| 位号 | 作用 | 备注 |
|---|---|---|
| L1 | 功率电感，接 VIN ↔ SW | 值与开关频率一起定，见 §5 提醒 |
| D1 | 肖特基二极管，SW → VOUT | 非同步拓扑，必须外置 |
| R_SENSE | 恒流采样（2.7Ω） | CSP / CSN 跨接 |
| R_FSET | 设定开关频率 | 59kΩ @ 400kHz |
| R_OVP1 / R_OVP2 | 输出过压保护分压 | |
| C_VIN | 输入电容 | |
| C_OUT | 输出电容 | |
| C_VCC | 内部 LDO 电容 **1µF** | 紧靠 VCC 脚 |
| C_COMP | 补偿电容 | 决定软启动时间与带宽 |
| C_SENSE | 采样滤波 | **TPS92365x 必须加**：R_SENSE 上的电流是断续的 |
| R_FLT + C_FLT | CSP/CSN 共模滤波 | |

### 3.5 调光接法

| 方案 | 做法 |
|---|---|
| **常亮（最简）** | EN/PWM 拉高 → 100% 电流，不需要任何调光信号 |
| **PWM 调光** | 主板 `LCD BL JACK` pin3（LCD-ADJ，40kHz）→ **直接进 EN/PWM**<br>（150ns 最小脉宽 ≪ 40kHz 周期 25µs，无需 RC 滤波） |
| 模拟调光 | PWM 信号进 ADIM/HD，256:1 |
| 混合调光 | ADIM/HD 拉低 |

> 注意：主板背光 PWM 是在 `LED+` 12V 轨上斩波的。取 12V 作输入时，要把 `pwm-backlight` 的
> `default-brightness-level` 从 200 改成 255（占空比 100%），`LED+` 才是干净的 12V。

## 4. 备选与排除

| 方案 | 评价 |
|---|---|
| **TPS923651**（TI，HVSSOP-8 / 3×3mm） | 8 脚更少，但**带散热焊盘**，手焊需热风枪 |
| **IS32LT3959A**（Lumissil，eTSSOP-28） | 0.65mm 间距对手焊友好，但升降压模式下需**外置 2 个 MOS + 2 个肖特基**，外围更复杂。Vin 4.5~55V，±3% 恒流精度，支持 buck/boost/buck-boost 三拓扑 |
| MP3302 / AP3031 / SY7201 等**纯升压** | ❌ 见 §2 |
| MT7203 / PT4115 等**纯降压** | ❌ 见 §2 |
| 线性恒流 sink（SM15201S / Hi1246 等） | ⚠️ 只在 Vf < 12V 时可用，见 §6 |

## 5. 两个必须注意的点

**① 80mA 属于这颗 IC 的「小电流」工况。**
它的满量程是安培级，80mA 只用到 2~4%。TI 有专门的应用笔记 **SLVAA392**，
第 **3.4 节 "Low LED Full Scale Current Improvement"** 讲的就是小满量程电流下电感与 C_SENSE 怎么调。
不照着调，小电流下的线性度和纹波会不如预期。

**② 引脚号不要照抄二手资料。** 见 §3.6。

## 6. 先量实际 Vf —— 可能省掉一半元件

手上这块屏已经在 T113 板上跑通了。**去量 T113 板上 LEDA 对 GND 的电压**，
那就是这块屏在 80mA 下的实际 Vf（再减去 R7 上的 0.2V）。

| 量到的值 | 结论 |
|---|---|
| ≈ **11.2 ~ 11.6V** | 12V 只多出 0.4~0.8V，**一颗线性恒流 sink（SOT23-5/6，几毛钱）就能干这活**，不用画升降压电路 |
| ≈ **13V** | 确认必须升降压，用 TPS923653 |

这是零成本的一步，做之前先量一下。
